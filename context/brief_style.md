# Brief style

- One brief per agenda item. Header: case number, title, meeting, brief language, status.
- Disclaimer at the top, in the brief language:
  - nb: «Utdrag som supplement til de fullstendige dokumentene, ikke en erstatning.»
  - nn: «Utdrag som supplement til dei fullstendige dokumenta, ikkje ei erstatning.»
  - en: "Supplement to the full documents, not a replacement."
- Extracts appear in document order within each relevance group (direct, supporting,
  cross_reference), unless the organiser reorders them.
- Each extract: the verbatim text as a block quote, then a reference line:
  document title · physical page N (printed page L) · section path · link to `…#page=N`.
- Extracts are always shown in the source language and never altered.
- Machine-written notes are labelled «Maskinskrevet merknad» / «Maskinskriven merknad» /
  "Machine-written note" and set in italics.
- An item with no relevant passages says so plainly and links the attachments.
- Pages that could not be searched (no text layer) are listed.
