# Coding-agent prompt logs

One file per session: `YYYY-MM-DD-<topic>.md`, with short excerpts (the appendix allows ≤ 2
pages). For each excerpt record:

- the request given to the agent;
- what it produced (trimmed);
- what the team **kept, corrected or rejected**, and why.

Corrected and rejected output is the most valuable part for the white paper.
